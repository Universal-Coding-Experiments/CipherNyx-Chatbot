# ✨ Build a Chatbot UI with JavaScript & Tailwind

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Vanilla JS](https://img.shields.io/badge/Logic-Vanilla--JS-yellow.svg)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

In this project, we design a sleek chatbot interface using HTML, Tailwind CSS, and JavaScript. The chatbot responds to user input with simple, predefined replies, simulating an AI assistant. This short tutorial demonstrates how to build a chat window, styled messages, and interactive input form, making it perfect for beginners who want to learn how to create dynamic chat applications.

---

### 🔗 Explore the Project
- **[⚡ Live Demo](https://universal-coding-experiments.github.io/CipherNyx-Chatbot/)**
- **[🤖 GitHub Repository](https://github.com/Universal-Coding-Experiments/CipherNyx-Chatbot.git)**

---

## 🚀 Key Features

- Interactive chatbot UI with styled messages.
- Predefined replies for quick demo interactions.
- Event listener to capture user input and display responses.
- DOM manipulation to append messages dynamically.
- Tailwind CSS utilities for modern design and layout.
- Custom scrollbar styling for polished look.
- Beginner‑friendly code with minimal setup.

## 💻 Getting Started

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/Universal-Coding-Experiments/CipherNyx-Chatbot.git
```

### 2️⃣ Quick Launch
No build system required! Open `index.html` directly in your browser or use a simple live server to see the GSAP Flip magic in action.
